# 🚀 CosmoLens

### Deep Sky & Satellite Visualization Platform

CosmoLens is a Python-based astronomy and satellite tracking application that combines real-time orbital visualization, Earth rendering, and scientific data visualization into a single interactive platform.

The project was developed as a personal exploration of astronomy, space technology, and scientific programming. It allows users to track satellites in real time, visualize their orbits, explore Earth from different perspectives, and better understand orbital mechanics through an interactive interface.

---

## ✨ Features

### 🛰 Satellite Tracking

* Real-time satellite visualization
* Live TLE data support
* SGP4 orbital propagation
* Orbit prediction and path rendering
* Ground footprint calculation

### 🌍 Earth Visualization

* Flat Earth map mode
* Interactive 3D globe mode
* Day/Night simulation
* Terminator line rendering
* Natural Earth coastline data

### 📊 Satellite Telemetry

* NORAD ID
* Altitude
* Velocity
* Inclination
* Orbital period
* Apogee and Perigee
* Latitude and Longitude

### 🔍 Search & Filtering

* Satellite search system
* Category-based filtering
* Quick satellite selection

### ⚡ Simulation Controls

* Pause/Resume
* Time Warp Engine
* Orbit preview
* Live updates

### 💾 Export Tools

* CSV export
* Screenshot capture
